# بوت النيترو والبوست

## الأوامر

- `-نيترو`: مراحل اشتراك النيترو لصاحب الرسالة.
- `-بوست`: مراحل شارة بوست الحساب لصاحب الرسالة.
- لا يحتاج منشن أو آيدي، ولا يقرأ إحصائيات شخص آخر عند إضافة منشن.

يعرض الاسم والصورة، Current Badge، Next Badge، Timeline، التوقيت النسبي للمرحلة القادمة. أمر البوست يختار صورة أصلية كاملة من الصور التسع المرفقة حسب مرحلة العضو، بدون قص أو إعادة رسم. يتغير الشريط عند الانتقال إلى المرحلة التالية، ويظهر الوقت المتبقي بالتوقيت النسبي في Embed. العضوان في نفس مرحلة البوست يعرضان نفس صورة المرحلة، وتختلف بياناتهما والوقت المتبقي في الرسالة.

أمر النيترو أيضًا يختار صورة المرحلة من ثماني صور: 1، 3، 6، 12، 24، 36، 60، 72+ شهرًا. الصور الست الأولى هي الصور المرفقة الأصلية، وصورتا 60 و72+ أُكملتا بنفس الفكرة باستخدام توليد الصور. عند 72 شهرًا فأكثر يعرض Max Level!. حقول Embed تستخدم إيموجيات البوت المخصصة بالمعرفات التي زودت بها. تتحدث النتائج عند إعادة الأمر؛ الرسائل القديمة لا تتغير تلقائيًا.

## مصدر البيانات وحدود الدقة

توكن البوت الرسمي وحده لا يعطي تاريخ اشتراك النيترو أو بداية سلسلة بوست الحساب. `GuildMember.premiumSince` يخص السيرفر فقط، ولا نستخدمه بدلًا من تاريخ الشارة.

للقراءة التلقائية، يوجد قارئ اختياري عبر `READER_TOKEN` لحساب تملكه، يطلب ملف صاحب الأمر فقط ويقرأ `premium_since` و`premium_guild_since`. ضَع حساب القارئ في السيرفر الذي توجد فيه الأوامر حتى تكون له إمكانية رؤية الأعضاء. لا يرسل القارئ رسائل ولا يطلب توكنات الأعضاء. الردود كلها من البوت الرسمي.

هذا مسار غير رسمي وغير مضمون: أتمتة حساب المستخدم تخالف شروط Discord وقد تؤدي إلى إغلاق الحساب. قد يمنع Discord الوصول أو يحجب التاريخ أو يغير الواجهة. عندئذ يظهر خطأ واضح؛ لا يتم اختلاق تواريخ ولا استخدام تاريخ السيرفر كبديل. بدون READER_TOKEN سيعمل البوت ويستقبل الأوامر لكنه يوضح تعذر القراءة التلقائية.

المراحل مأخوذة من الصور المرفقة: النيترو 1، 3، 6، 12، 24، 36، 60، 72 شهرًا؛ البوست 1، 2، 3، 6، 9، 12، 15، 18، 24 شهرًا. النيترو يظهر بالشارة الأساسية قبل شهر، ثم Bronze عند اكتمال شهر. البوست يبدأ بأول رمز حتى اكتمال شهرين. التقدير بالشهور الميلادية مع معالجة نهاية الشهر والسنة الكبيسة، لا باعتبار الشهر 30 يومًا. لا يغطي الحساب تغييرات Discord في مراحل الاشتراك أو فترات السماح؛ القرار النهائي للشارة عند Discord. يوجد تخزين مؤقت في الذاكرة لمدة 30 ثانية ولا توجد قاعدة بيانات.

## إعداد Discord

1. أنشئ تطبيقًا وبوتًا من https://discord.com/developers/applications .
2. في Bot فعّل Message Content Intent لقراءة الأوامر النصية.
3. أضف البوت إلى سيرفرك بصلاحيات View Channels وSend Messages وEmbed Links وAttach Files وRead Message History. لا يحتاج Administrator أو Server Members Intent.
4. خزّن BOT_TOKEN وREADER_TOKEN في إعدادات الاستضافة فقط، ولا ترسلهما في الديسكورد أو المحادثة ولا ترفعهما إلى GitHub.

## التشغيل محليًا

Node.js 22.12 أو أحدث. انسخ `.env.example` إلى `.env` وأضف القيم ثم:

```sh
npm ci
npm test
npm start
```

متغيرات البيئة:

| المتغير | الاستخدام |
|---|---|
| BOT_TOKEN | توكن البوت الرسمي الذي يرد على الأوامر؛ مطلوب |
| READER_TOKEN | حساب القارئ؛ مطلوب لتفعيل قراءة الشارات تلقائيًا |
| GUILD_ID | اختياري؛ لتقييد الأوامر بسيرفر واحد |

## Render

ارفع محتويات هذا المجلد إلى مستودع GitHub خاص، بدون `.env` أو node_modules. أنشئ Background Worker واربط المستودع. Build Command: `npm ci`. Start Command: `npm start`. أضف المتغيرات المذكورة. مرفق render.yaml أيضًا؛ لا توجد حاجة لمنفذ HTTP أو MongoDB. قد تتطلب خدمة Worker خطة مدفوعة حسب حسابك وخيارات Render.

## التحقق

اختبارات محلية للشهور والسنة الكبيسة وحدود الترقيات واختلاف بيانات الأعضاء ومصدر كل تاريخ والتخزين المؤقت وحدود الطلبات وأخطاء الاعتماد. لم يتم إجراء تجربة حية بتوكنات Discord. نجاح الاختبارات لا يثبت سماح Discord بالواجهة غير الرسمية لحسابك.

## إصدار 1.3 — تنسيق الرسالة حسب المرجع

Current Badge وNext Badge بجانب بعضهما، ثم Timeline لأقرب خمس مراحل فقط. عند أعلى مستوى يظهر Max Level! ويختفي Timeline. أزيلت حقول تاريخ البداية والعد التنازلي التفصيلي ونسبة التقدم من الرسالة. تذييل الرسالة يعرض اسم البوت وصورته؛ تم استبدال الرموز التقريبية بإيموجيات البوت المخصصة في إصدار 1.5.

## إصدار 1.4 — مراحل النيترو كاملة

أضيفت صور 60 و72+ واستبدل مولّد النيترو باختيار صور المراحل. البوت والقارئ والأوامر كما هي. صورة 60 في assets/nitro/60-months.png وصورة 72+ في assets/nitro/72-months.png.

## إصدار 1.5 — إيموجيات البوت

تم ربط أسماء ومعرفات الإيموجيات المرفقة في صورك: discordboost1 إلى discordboost9 مع مراحل البوست، وbronze وSilver وGold وPlatinum وDiamond وEmerald وRuby وOpal مع مراحل النيترو. تظهر في Current Badge وNext Badge وTimeline. المعرفات محفوظة كنصوص في src/badges.js لتجنب فقدان دقة Snowflake. شغّل نفس البوت الذي رفعت إليه الإيموجيات؛ عند استخدام بوت آخر أو إعادة رفع الإيموجيات حدّث المعرفات في الملف. لا توجد متغيرات بيئة جديدة.

## إصدار 1.5.1 — اسم بداية البوست

تظهر أول مرحلة باسم Started Boosting. بعدها يتغير الاسم تلقائيًا حسب تاريخ الحساب عند كل طلب. عند 15 شهرًا مثلًا يبقى في Timeline مرحلتا 18 و24 شهرًا فقط. الرسائل القديمة تحتفظ بالمرحلة وقت إرسالها، بينما توقيت Discord النسبي يتغير مع الوقت.

## إصدار 1.6 — حالة النيترو قبل شهر

قبل الشهر الأول يظهر Nitro بالإيموجي <:Nitro:1559005534169071647>، وتكون المرحلة القادمة Bronze عند شهر. أضيفت صورة مراحل محايدة لهذه الحالة. عند إكمال شهر ينتقل إلى Bronze وصورة الشهر، ولا يتغير حساب مراحل البوست.

عند اكتمال 72 شهرًا في النيترو: Current Badge = Opal / 6 Years، وNext Badge = Max Level!، بدون Timeline، مع صورة 72+؛ بنفس تنسيق أقصى بوست.
